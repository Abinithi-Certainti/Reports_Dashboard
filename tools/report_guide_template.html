What each report is for, how it is built, which tables and fields it reads, and the formula behind every number, next to the old Power BI formula it replaces.

How every report works

1 · TablesThe report reads read-only from the new PostgreSQL database, kios_etl, schema master.
2 · dataset.sqlOne SELECT per report joins the tables and applies the business rules (renames, latest budget load, paid-outs). It never writes.
3 · report.yamlNames the fields (dimensions), the formulas (measures), the filters and the charts. There is no code, only settings.
4 · Java engineWraps the dataset with your filters and groups it for each chart. Week, period and year-to-date windows run as extra queries on the retail calendar.
5 · React pageDraws the number cards, charts and tables. Click a plaza name to see its details.
