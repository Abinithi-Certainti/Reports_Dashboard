# QA vs DEV - schema master (2026-09-28)

Source: `tools/compare_db_structure.sql` and `tools/compare_db_coverage.sql`, run by the user on QA and DEV
(SELECT only). Row counts and dates are kept outside git (`demo/private-data/qa_dev_coverage_2026-09-28.tsv`).

## Summary
- QA has **57 tables**, DEV has **97**. Every QA table is also in DEV. **40 tables are only in DEV.**
- On the 57 shared tables, the columns are the same except **employee_pay_summary** and **credentials_reference**.
- Data: QA and DEV hold **different periods** (QA: September 2026, DEV: May to July 2026), so they cannot be compared
  number for number. Neither holds last year's sales, so no report can show PY / YOY yet.

ceridian_employees and the qrtz_* scheduler tables have the same columns and types in both.
