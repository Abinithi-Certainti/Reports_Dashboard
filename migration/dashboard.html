How to update this page, and what never to upload
  1. Run the migration as usual: python3 migrate.py --env my.env (or with --dry-run).
  2. While it runs, or after, upload run/progress.json here. Everyone who has the page open sees the new numbers straight away.
  3. Upload only progress.json. It holds table names, counts, totals and reasons, with no rows, server names or passwords. The page checks the file and refuses anything else.
  4. Never upload my.env (passwords), errors/*.csv (real rows) or checkpoint.json.
